## Block 1: Stage 1 — Spoken Code Punctuation & PR Review
```text
💻 STAGE 1: LIVE CODE NARRATION
Punctuation to use out loud (no "two points"!):
• :  → colon
• ;  → semicolon
• => → arrow function
• <T> → generic type T
• ?: → optional property
• ?. → optional chaining
• ?? → nullish coalescing
```
