## Block 2: NEW SKILL 1 — The Tech Phrasal Verb Decoder (`OUT • UP • OFF • DOWN`)
```text
🧠 GROUP BY THE PARTICLE (Not the Verb!):

1️⃣ [ OUT ] = Expand outward OR Eliminate a problem
• ROLL OUT     = deploy gradually ("We'll roll it out on Monday")
• IRON OUT     = smooth out small bugs ("Let's iron them out first")
• RULE OUT     = eliminate a cause ("We ruled out a database issue")

2️⃣ [ UP ] = Make visible / Launch
• FLAG UP      = raise a risk/warning early ("I want to flag up an edge case")
• SPIN UP      = launch a server/test environment quickly
• BRING UP     = raise a topic in a meeting

3️⃣ [ OFF ] = Start / Approve / Postpone
• KICK OFF     = start a meeting or sprint
• SIGN OFF ON  = officially approve ("Once QA signs off on it...")
• PUT OFF      = postpone to later ("Let's put it off until Sprint 2")

4️⃣ [ DOWN ] = Split into pieces / Funnel
• BREAK DOWN   = split a big feature into small tickets
• NARROW DOWN  = reduce 10 bug theories down to 1 ("We narrowed it down to CSS")

🥪 THE PRONOUN SANDWICH RULE:
Put IT or THEM in the middle!
✅ "Roll IT out" • "Iron THEM out" • "Put IT off" • "Narrow IT down"
⚠️ 3-word exception: "Sign off on IT" (stays at the end!)
```

## Block 3: NEW SKILL 2 — The 45-Second "BLUF" Standup Frame (No Rambling!)
```text
⏱️ BLUF = BOTTOM LINE UP FRONT (Max 45 Seconds!)
Never tell a long detective story in a meeting. Hit these 3 bullets:

1. HEADLINE (10s):
   "Quick update on [the checkout bug / dashboard feature]..."
2. RULED OUT + NARROWED DOWN (20s):
   "We RULED OUT [X] and NARROWED IT DOWN to [Y]. I'm IRONING IT OUT now."
3. NEXT STEP / ASK (15s):
   "To ROLL IT OUT tomorrow, I just need [Backend / QA] to SIGN OFF ON [Z]."
```

## Block 4: NEW SKILL 3 — Scope Creep Pushback & UX Product Rescue
```text
🛡️ SCENARIO A: STOPPING FRIDAY SCOPE CREEP
PM says: "Can we squeeze in dark mode + PDF export before Monday's release?"
• Step 1 (Validate): "I can see how valuable that is for users..."
• Step 2 (Flag Up Risk): "...however, I want to FLAG UP a risk to Monday's stability."
• Step 3 (Trade-Off): "Let's ROLL OUT the core release first, PUT OFF the PDF export until next sprint, and BREAK IT DOWN properly."

🎨 SCENARIO B: LIVE UX & ACCESSIBILITY RESCUE (60s Pitch)
Problem: 68% of patients over age 60 abandon a clinic's appointment booking web app.
• Pitch 3 Frontend/UX fixes using:
  - "reduce cognitive load"
  - "break down the multi-step form"
  - "iron out accessibility bottlenecks"
  - "roll out a simple A/B test"
```
